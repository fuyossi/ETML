## How to build the compiler
Windows user:
```powershell
gcc -o "path\to\output\etml.exe" "path\to\source\etml.c"
```
Mac or Linux user:
```bash
gcc -o /path/to/output/etml /path/to/source/etml.c
```
And just put to the folder wherever you want, like `C:\etml` or `/usr/local/bin`.  
  
Or you can download the pre-builded binary from the release page.

## Compiler usage
```bash
etml file.etml -o file.html
```
